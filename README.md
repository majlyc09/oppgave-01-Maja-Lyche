# Oppgave 01 – Terminal, Git og Python



Du har nå:



laget ditt eget repository fra template

installert Git

laget en mappe for prosjektene dine

clonet repositoryet til PC-en



Nå skal du fortsette å jobbe gjennom terminalen.



## **1. Installer Python**



Sjekk først om Python allerede er installert: *python --version*



Hvis Python ikke er installert, søk etter Python: *winget search Python.Python*



Installer en tilgjengelig Python 3.14-versjon.



for eksempel: *winget install -e --id Python.Python.3.14*



Når installasjonen er ferdig, åpne terminalen på nytt og test: *python --Version*



## **2. Lag en Python-fil**



Lag en ny fil som heter:
main.py

new-Item main.py

rediger filen med:
edit main.py
eller
nano main.py

I filen skal du legge til følgende:



\# dette er Python



## **3. Commit Python-filen**



Sjekk først hva Git ser: *git status*



Legg til Python-filen: *git add main.py*



Sjekk hva Git ser igjen: *git status*



Lag en commit: *git commit -m "Opprettelse av python fil"*



Sjekk hva Git ser igjen: *git status*



## **4. Lag en fil med navnet ditt**



Lag en Markdown-fil med fornavnet ditt som filnavn.



Eksempel:



*notepad ola.md*



I filen skal du skrive en funfact om deg selv.



Eksempel:



\# Ola

En funfact om meg er at jeg har hoppet i fallskjerm.



## **5. Lag en ny commit**



Legg til filen: *git add* 



Lag en commit: *git commit -m "Funfact opprettet"*



## **6. Sjekk status**



Kjør: *git status*



Les hva Git forteller deg.



## **7. Push til GitHub**



Legg til eventuelle endringer: *git add* .



Push prosjektet: *git push*



## **8. Sjekk status igjen**



Kjør: *git status*



Gå deretter inn på repositoryet ditt på GitHub.



## **Ferdig**

Kontroller at du kan se:



README.md

main.py

Markdown-filen med navnet ditt

commitene dine
